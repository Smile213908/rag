## 2. 关键发现

### 2.1 延迟严重超标(唯一不通过项)
- 事实型问答端到端 40~106s,构成:**CRAG 质检 LLM 调用(串行,约 10s+)+ k3 推理模型生成(30~90s)**;
- 库外拒答也不快:阈值层拒答约 10s,CRAG 层拒答 10~51s;
- **根因**:k3 为推理模型,生成长思维链导致秒级~分钟级延迟,与 PRD「简单问题 ≤8s」的假设(快模型)冲突;
- 缓解:流式输出已上线,用户感知的 TTFT(首字时间)远小于总时长,但 PRD 指标口径是端到端。

### 2.2 CRAG 层新增一例库内误杀(F06)
- 「私车公用去出差,油费补贴按什么标准计算?」top_score **0.9603**(高分)仍被质检层判「不支撑」拒答;
- 此前「库内零误杀」结论在更大样本下出现反例,已登记 `logs/bad_cases.jsonl`(status: open);
- 假设:高分带(≥0.95)可跳过 CRAG 只查中间分带,或优化质检 prompt——留 M2 验证。

### 2.3 答案质量本身过硬
- 人工复核 15 条「自动子串未命中」的答案**全部正确**,且普遍带条款级引用与例外情形说明;
- 自动子串匹配低估了正确率(30.4% vs 实际 95.7%),措辞差异是主因——评估口径本身需要 LLM 裁判(RAGAS,v2 计划)。

## 3. 处置建议(进 M2 规划)

| 优先级 | 事项 | 说明 |
|--------|------|------|
| P0 | **模型路由/换快模型** | 简单事实型问题路由到非推理模型(如 k2 系列),推理模型留给复杂问题;或缩短 max_tokens 限思维链 |
| P0 | **CRAG 分带启用** | top_score ≥0.95 直放、0.7~0.95 走质检、<0.7 拒答,既省 10s 又规避 F06 类误杀 |
| P1 | PRD 指标校準 | 8s 目标与推理模型路线冲突,需修订口径(如区分 TTFT 与完整答案)或待模型路由后复测 |
| P1 | RAGAS 生成层评估(v2) | 替代子串匹配,覆盖综合/多跳 16 条未测条目 |

## 4. M1 总评

**功能完整性**:路线图 M1 八个工作项全部落地(服务化/拒答/溯源/流式/文档管理/前端/反馈/评估集)。
**质量结论**:可信度指标(拒答率、正确率、溯源率)全部达标且有余量;**体验指标(延迟)不达标,是 M2 的第一优先级**。
建议:M1 判定为「**有条件通过**」——质量门槛全过,延迟项挂账进 M2 P0。

## 5. M2 P0 治理复测(2026-07-30,模型路由 + CRAG 提速)

**改动**:① CRAG 质检从 k3 改走 `kimi-for-coding`(2~4s)并换 few-shot prompt(明确「间接条款算支撑」边界);② 生成层模型路由——高置信短问题(top_score ≥0.85 且 ≤30 字)走 `kimi-for-coding`,复杂问题留 k3;③ `/chat/ask/sync` 上游 LLM 异常由裸 500 改映射 503。
**关键设计否决**:验收报告原设想「top_score ≥0.95 跳过 CRAG」被数据否决——3 道域邻近对抗题分数 0.954~0.982 与 F06(0.9603,库内)同分布,跳带会把拒答率打回 72.7%;故 CRAG 全分带保留,只提速。

| 指标 | M1 基线 | M2 复测 | 结论 |
|------|---------|---------|------|
| 库外拒答率 | 100% | **11/11 = 100%** | ✅ 保持 |
| 事实型 Top-1 正确率 | 95.7%(22/23,F06 误杀) | **23/23 = 100%**(F06 修复,人工复核 14 条全对) | ✅ 提升 |
| 来源覆盖率 | 100% | **23/23 = 100%** | ✅ 保持 |
| 事实型延迟 P50 / P95 | 55.6s / 71.5s | **26.0s / 53.0s**(P95 含上游 429 过载期取样) | ⚠️ 降 26%~54%,仍超 8s |
| 误杀 / 误编 | 1 / 0 | **0 / 0** | ✅ 清零 |

**结论**:质量指标全绿且 F06 类误杀根除;延迟显著改善但 8s 目标仍不可达——k3/快模型均为思考型模型,生成 token 成本是硬下限。**建议 PRD 延迟口径修订为「TTFT ≤ 3s(流式已达标)+ 简单问题端到端 ≤ 30s」**,或 v2 继续压(生成 max_tokens 封顶、答案长度约束)。原始数据:`eval/results/accept_report_20260730_164314.json`(M1 基线 `accept_m1_baseline.jsonl`)。
